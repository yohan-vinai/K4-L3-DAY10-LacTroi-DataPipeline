## 4. Giải thích phần kỹ thuật đã thực hiện

### Vấn đề cần giải quyết

Phần Data Core bảo toàn metadata nguồn, chuẩn hóa thành schema cho embedding, tạo corruption có thể lặp lại và khôi phục clean data từ raw.

### Cách triển khai

Parser trích DOI, title, abstract JATS, authors, subjects, ngày xuất bản/cập nhật và URL. Ingestion mặc định dùng snapshot; khi bật `REFRESH_SOURCE`, hàm gọi Crossref, retry HTTP 429/502/503/504 và fallback về snapshot khi request lỗi. Cleaning chuẩn hóa Unicode NFKC/whitespace, đặt `Unknown`/`General` cho authors/categories thiếu, tính `age_days`, tạo joined fields và ghép `text_for_embedding` theo 5 trường. Record thiếu ID/ngày hoặc title/summary dưới 10 ký tự bị loại; dữ liệu được deduplicate theo `paper_id`. Corruption dùng seed 42, ghi log JSON và cập nhật embedding text. Repair đọc lại raw records thay vì sửa dữ liệu corrupted.

### Input, output và contract

| Thành phần                   | Mô tả                                     |
| ------------------------------ | ------------------------------------------- |
| Input                          | Crossref response JSON hoặc parsed `PaperRecord`; `run_date` |
| Output                         | Raw records; clean DataFrame có `age_days`, joined fields, `summary_chars`, `text_for_embedding` |
| Module phụ thuộc             | `core.config`, `core.utils`, pandas, requests |
| Module sử dụng output        | Pipeline, quality/evaluation, retrieval/index |
| Điều kiện lỗi cần xử lý | API lỗi dùng snapshot fallback; payload rỗng/bất hợp lệ báo lỗi; corruption yêu cầu clean columns |

- **Artifact/log:** `data/raw/crossref_response.json`, `data/raw/crossref_records.json`, `data/clean/papers_clean.csv/json`.

## 5. Một quyết định kỹ thuật quan trọng

- **Bối cảnh:** Môi trường không phân giải được Crossref API trong lần thử live.
- **Các phương án đã cân nhắc:** Chờ mạng live hoạt động hoặc dùng snapshot offline có sẵn.
- **Phương án đã chọn:** Dùng snapshot cho pass signal CP0; giữ live fetch và fallback trong code.
- **Lý do:** README khuyến nghị chế độ offline; snapshot tái hiện được và có đủ 24 records.
- **Bằng chứng quyết định phù hợp:** CP0 command trả 24; request live lỗi DNS nên không ghi nhận là crawl live thành công.

## 6. Một lỗi hoặc blocker đã xử lý

- **Triệu chứng:** Repair smoke flow ban đầu trả về 0 dòng.
- **Lệnh hoặc bước tái hiện:** Đọc parsed `crossref_records.json`, sau đó gọi `repair_clean_from_raw`.
- **Nguyên nhân gốc:** Parser nhận `DOI`/`doi`, nhưng parsed record dùng `paper_id`.
- **Cách xử lý:** Bổ sung `paper_id` làm khóa đầu vào parser.
- **Cách xác minh sau khi sửa:** Smoke flow trả 24 repaired rows và `baseline.equals(repaired) == True`.
- **Điều học được:** API payload và parsed raw record cần contract đọc tương thích.
